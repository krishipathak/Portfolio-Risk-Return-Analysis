# Portfolio Risk & Return Analysis

A portfolio analytics project combining **Python for data processing and financial calculations** with **Power BI for interactive visualization and dashboarding**.

## Project Overview

- Collected historical stock price data using Python
- Cleaned, standardized and combined stock-level data
- Calculated portfolio returns and portfolio value
- Analyzed risk using volatility, variance, covariance and correlation
- Evaluated performance using Sharpe Ratio, Beta, Jensen's Alpha and Treynor Ratio
- Compared portfolio performance with the **NIFTY 50 benchmark**
- Built an interactive **Power BI dashboard** for portfolio risk and performance analysis

## Tools & Techniques

**Python | Pandas | NumPy | yfinance | Power BI | DAX**

## Project Structure

- Portfolio_Data_Collection.ipynb – Data collection, processing and portfolio calculations
- Portfolio_Risk_Return_Analysis.pbix – Power BI dashboard and visualization

## Key Outcome

Built an end-to-end portfolio analysis workflow from **market data processing in Python to interactive risk and performance analysis in Power BI**.
